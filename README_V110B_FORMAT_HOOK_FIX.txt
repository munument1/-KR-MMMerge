MMMerge 한국어판 v1.0.10b 전역 포맷 훅 제거 시험판
=====================================================

야로 승급 안내는 Lua string.format이 아니라 MM8 실행 파일 내부 코드에서 조합됩니다.
따라서 이전 시험판의 전역 string.format 교체는 야로 문제를 해결하지 못하면서 다른 Merge Lua 스크립트의 포맷 처리에 영향을 줄 수 있었습니다.

이번 수정
- Lua 전역 string.format 교체 제거
- 같은 게임 실행 중 스크립트를 다시 불러온 경우 기존 훅 자동 복구
- GlobalTxt[632] = %s 1개
- GlobalTxt[633] = %s 1개
- GlobalTxt[634] = 연결어 "또는", %s 없음
- 검사기에 구형 전역 포맷 훅 잔존 여부 검사 추가

게임을 완전히 종료한 뒤 설치하십시오. 야로의 창 그랜드마스터 항목과 일반 NPC 대화를 함께 확인해야 합니다.
