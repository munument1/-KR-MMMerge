MMMerge 한국어 UI 소실 조사 — test1 (v1.0.15 기반)
=================================================
이 패키지는 정식 v1.0.16 릴리스가 아닌 테스트본입니다.
장시간 플레이 중 UI 소실이 해결됐는지는 아직 확인하지 못했습니다.

포함 변경
- 긴 줄바꿈 출력은 별도 4096바이트 버퍼에 보관합니다.
  기존 2048바이트 게임 버퍼에는 안전한 길이의 내용만 기록합니다.
  기존 4095바이트 출력 한도는 유지하며, 배포 연대기 3711바이트
  본문이 사라지지 않는 것을 오프라인 검사했습니다.
- Lua에서 Font:WordWrap(..., ReturnPointer=true)를 사용하는 경우도
  긴 출력의 전체 바이트 배열을 반환합니다.
- 줄바꿈 캐시를 256개 / 문자열 합계 512KiB 이하로 제한하며,
  지도 불러오기 후 비웁니다. 512KiB는 테이블 관리 비용을 제외한 값입니다.
- 진단 기록 기능을 추가합니다. 게임 상태를 강제로 복구하지 않습니다.

권장 시험 순서
1. 제보자가 쓰던 v1.0.15 게임 폴더를 별도 폴더로 복사합니다.
2. 먼저 DiagnosticsOnly ZIP의 Data, Scripts를 복제 폴더에 복사합니다.
   이 ZIP은 번역이나 폰트 렌더러를 바꾸지 않습니다.
3. 평소와 같은 방식으로 충분히 플레이합니다. 정상 상태에서 한 번,
   UI가 사라진 순간에 한 번 Ctrl+Alt+F10을 누릅니다.
4. 문제 상태를 저장 후 불러와 복구되면 Ctrl+Alt+F10을 다시 누릅니다.
5. 로그를 따로 보관한 뒤 FullTest ZIP의 Data, DataFiles, Scripts를
   복제 폴더에 덮어쓰고 같은 방식으로 시험합니다.

FullTest ZIP은 v1.0.15의 번역/폰트를 포함한 전체 한글 테스트 패키지입니다.
게임 실행 파일, GrayFace DLL, Merge 본체, 세이브는 포함하지 않습니다.
원래 MM8/MMMerge가 정상 설치된 폴더에 적용해야 합니다.

보내줄 파일 (게임 폴더 최상위)
- KO_UI_Incident.log 및 같은 이름 뒤에 .previous가 붙은 파일
- KO_UI_Diagnostic.log 및 같은 이름 뒤에 .previous가 붙은 파일
- mm8.ini
발생 직전 행동과 정상화 방법도 간단히 알려주세요.
단축키는 창이나 소리를 띄우지 않으므로 게임 화면상 반응이 없어도 됩니다.
게임 콘솔에서 KoreanUIDiagnostics.Mark()를 실행해도 같은 표시를 남깁니다.

진단 기록의 의미
- Begin2D-entry/return/failed: 2D 그리기 시작 전후 관측
- FG-before-End2D: Merge 전경 UI 이벤트 시점, 그리기 종료 직전 관측
- Tick-outside-draw: 그리기 구간 밖일 수 있으므로 count=0은 정상일 수 있음
- usage: Lua 메모리, 가능한 경우 프로세스 메모리, 수정본 캐시 상태
- USER-MARK: Ctrl+Alt+F10을 누른 시점
5초 단위 샘플과 누적 호출/실패 횟수를 기록합니다. 모든 프레임의 기록은 아닙니다.
각 로그는 2MiB에서 이전 파일로 교체하며 각 종류당 현재/이전 파일을 보관합니다.
장시간 시험 중에는 기록을 잃지 않게 재발 후 로그를 별도 보관하세요.

진단 기능은 원래 MM8 Begin2D 함수의 시작 바이트가 일치할 때만
해당 함수 진단 hook을 설치합니다. 설치 불가 이유도 로그에 남깁니다.
Merge가 이미 hook을 사용하는 End2D에는 추가 hook을 설치하지 않습니다.
관측 오버헤드로 발생 타이밍이 달라질 수 있습니다.

진단 종료 / 원상 복구
- Data/KO_UIDiagnostics.ini에서 Enabled=0으로 바꾸고 재시작하면
  진단 기능 전체가 꺼집니다. NativeBegin2D=0은 native probe만 끕니다.
- 수정본을 되돌리려면 시험 전 복사해 둔 폴더로 돌아갑니다.
  기존 v1.0.15 전체 패키지를 다시 덮어쓸 경우에도 별도로
  Enabled=0을 설정해야 새 진단 스크립트가 비활성화됩니다.

추가 A/B (별도 시험)
진단이 끝난 복제 설치에서 mm8.ini의 [Settings] UILayout=UI를
UILayout= 로 비워 시험할 수 있습니다. 렌더러 변경 시험과 동시에
바꾸지 말고 기존 값을 기록해 두세요. 짧은 무발생만으로 해결 판정하지 않습니다.

검증 범위
- Lua 5.1 구문 검사
- 기존 upstream 모의 하네스 53개 통과
- 한국어 실제 페이지/배포 연대기를 사용한 추가 모의 검사 18개 통과
- 한글 페이지 파일 내부 glyph 경계 및 배포 ZIP 해시 확인
실제 x86 hook 실행과 DirectDraw 화면 합성, 장시간 플레이는 미검증입니다.
