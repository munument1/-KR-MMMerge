MMMerge 한국어판 v1.0.10 런타임 현지화 시험판
================================================

이번 시험판은 번역 파일에 한국어가 존재하는데도 MM6 NPC 소문·주제·본문이 영어로 표시되는 문제를 수정합니다.

핵심 변경
- Merge의 캐시 생성 전: MapStats, NPCTopic, NPCText 등 안전한 원본 테이블을 먼저 한글화
- Merge의 캐시 생성 후: 전체 번역을 다시 적용하고 영어로 남은 파생 캐시를 복구
- NPCNews/NPCNewsTopics: 원문 본문 뒤에 주제가 이어지는 메모리 구조를 먼저 보존한 뒤 안전하게 한글화
- 동적 NPC 주제, 인사말, 전환 문구에도 최종 출력 안전망 적용
- 검사기가 번역 파일 구조뿐 아니라 실제 런타임 값과 파생 캐시도 비교

우선 확인 위치
- MM6 뉴 소르피갈: 보물, 니콜라이, 해적의 소굴
- MM6 자유 항구 및 여관: 노상강도, 오라클, 동행 여행자
- MM6 에메랄드 섬: 드래곤 동굴 대화
- MM7/MM8: 무작위 NPC 소문과 마을 이동 목적지

기존 저장과 새 게임을 모두 확인해야 합니다. 게임을 완전히 종료한 뒤 덮어쓰십시오.
