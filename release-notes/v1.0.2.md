## Might and Magic 6·7·8 Merge 한국어 패치 v1.0.2

잘못 포함된 구버전 스크립트와 재가공된 대화 파일을 바로잡은 교정 릴리스입니다.

### 수정 사항

- `KO_NPCText`, `KO_NPCGreet1`, `KO_NPCGreet2`를 사용자가 제공한 원본 바이트 그대로 복원
- `Scripts\General\History.lua:69: unfinished string near` 오류를 일으킨 폐기 파일 제거
- NPC 이름 남성 539개·여성 310개 번역 유지
- 주문 132종 번역과 현지화 로더 수정 유지

### 업데이트 시 주의

v1.0 또는 v1.0.1을 설치했다면 게임 폴더의 다음 파일을 직접 삭제한 뒤 새 패치를 덮어쓰십시오.

```text
Scripts\General\History.lua
```

새로 설치하는 경우에는 별도 삭제 작업이 필요하지 않습니다.
