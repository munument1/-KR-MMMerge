## Might and Magic 6·7·8 Merge 한국어 패치 v1.0.5

MM6의 History 화면에 MM8 `파멸자의 날` 내용이 남던 문제를 수정한 릴리스입니다.

### 수정 사항

- MM8 한국어 기록 18개와 MM7 한국어 기록 27개를 대륙에 맞게 로드
- MM6 진입 시 공용 History 테이블을 교체하고 전용 `엔로스 연대기` 소개 표시
- 구버전에서 남은 혼합 `KO_HistoryTxt.txt` 자동 제외
- `Data\Text localization`에서 `KO_*.txt`만 읽어 덤프·백업 파일 오적용 방지
- 폐기된 `Scripts\General\History.lua` 대신 충돌 없는 `KoreanHistory.lua` 추가
- MM8 첫 기록을 한글 제어코드 적용 후에도 8KB 내부 버퍼를 넘지 않는 검증된 번역으로 복구
- 마차회사 이동 문구 3곳의 `%d`·`%s` 순서를 원문과 맞춰 진입 충돌 수정
- 작은 글씨는 2026-07-28 09:14 실제 게임 백업에서 복원
- 서적의 29픽셀 큰 제목만 충주김생체로 적용
- `말썽` 누락 글리프를 피하도록 시스템 문구를 `문제를 일으키지 마시오`로 교정

### 런타임 검증

- MM8: 한국어 18개 기록, 첫 제목 `파멸자의 날`
- MM7: 한국어 27개 기록, 첫 제목 `저자의 서문`
- MM6: 한국어 `엔로스 연대기` 1개

### 이전 버전에서 업데이트

ZIP의 `Data`, `DataFiles`, `Scripts` 폴더를 게임 폴더에 그대로 덮어쓰면 됩니다. 구형 `KO_HistoryTxt.txt`가 남아 있어도 자동으로 무시되지만, 오래된 `Scripts\General\History.lua`가 있다면 삭제하십시오.
