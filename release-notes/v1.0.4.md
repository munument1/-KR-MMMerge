## Might and Magic 6·7·8 Merge 한국어 패치 v1.0.4

한국어 글꼴을 화면 용도에 맞게 교체한 릴리스입니다.

### 폰트 변경

- 작은 UI 글씨(14·15·16픽셀): 프리텐다드 SemiBold
- 서적 및 큰 글씨(29픽셀): 충주김생체
- 작은 UI 글씨 및 보존 문장부호의 그림자 픽셀 제거
- EUC-KR 완성형 한글 전체 생성
- 번역 텍스트에서 사용하는 DBCS 문자 1,296자 누락 없음

### 추가 수정

- 깨진 저장 슬롯 제목을 해당 맵의 영문 이름으로 자동 복구
- 수정 전 저장파일을 `.ko-title-backup`으로 한 번 백업
- 새 저장 후 손상된 제목도 자동 복구
- `New Sorpigal` 표지판 철자 오류 수정
- 지도 이벤트 문자열이 힌트로 복사되기 전후 모두 지명 번역 적용

폰트 출처와 이용 조건은 저장소의 `FONT_LICENSES.md`를 참고하십시오.

### 이전 버전에서 업데이트

v1.0 또는 철회된 v1.0.1을 설치했다면 게임 폴더의 다음 파일을 삭제한 뒤 덮어쓰십시오.

```text
Scripts\General\History.lua
```
